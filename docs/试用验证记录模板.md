# Looma v5 7 天试用验证记录模板

状态：空白模板，实验尚未执行。仅用于项目负责人安排的目标用户试用，不代表已有商业成绩。

## 使用方式

由负责人邀请 5 名独立接单者、顾问或小工作室主理人，自愿完成 7 天试用。使用匿名编号 U01 至 U05，不记录姓名、联系方式或完整客户内容。真实业务案例只填脱敏描述；原始资料留在参与者设备，不随本表上传。产品不默认远程采集本实验数据。

为每位用户选择任务量和复杂度接近的案例，先按原方式整理，再使用 Looma。记录是否受到指导、案例熟悉程度和中断情况，避免把第二次操作的熟练优势完全算作产品收益。

先询问“网站开发者同时处理多个客户，沟通后要区分我方发原型、等待客户补素材和费用未定”是否接近其工作。该情境是假设案例，参与者可明确说不适用；不可把回答改写成既有研究结论。若不适用，记录其真实、脱敏的接续场景，再决定是否纳入本轮目标群体。

整理耗时口径：从开始阅读或输入该案例，到沟通收尾成功，且用户能分清已核对记录、我方行动、等待客户及未定问题。模型等待、修改和失败重试均计入；受外部中断时单独标注，不静默扣除。

耗时变化 =（原方式耗时 - Looma 耗时）÷ 原方式耗时。原方式为零或案例不可比时不计算百分比。汇总同时报告每位用户原始值、中位数与范围，避免只展示最好案例。

纪要采用口径：参与者实际使用其内容进行客户沟通或内部整理，不要求发送给研究方，也不收集接收者信息。导出次数与采用次数分开记录；采用不等于获客或新增付费用户。

## v5 旅程观察
