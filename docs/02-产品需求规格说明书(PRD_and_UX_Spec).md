# Looma（灵犀胶囊）产品需求规格说明书 (PRD & UX Specification)

> **文档版本**：v2.0（ToC + ToB 双擎商业化版）  
> **设计北极星指标**：**普通用户 30 秒内完成第一次“说话即建卡改数”的魔法体验（Time-to-First-Magic < 30s），全流程零表单录入。**

---

## 一、 全局双态空间设计：「🌙 生活态」与「💼 搞钱态」瞬切规范

为了确保同一款桌面常驻软件既能在深夜独处时提供极致温暖，又能在白天办公室、会议投屏、客户洽谈时展现出超越百万级企业软件的专业度，系统顶栏常驻 **【双态空间切换器（Dual-Vault Switcher）】**：

| 维度 | 🌙 生活态 (Life Mode - ToC) | 💼 搞钱态 (Work Mode - ToB) |
| :--- | :--- | :--- |
| **视觉主色调** | **暖羊皮纸色 (`#F7F4EC`) + 琥珀金 (`#A8681A`)**<br>圆润亲和、纸质纹理、微光呼吸感 | **深空曜石蓝 (`#0F172A`) + 科技翠/商务蓝 (`#3B82F6` / `#10B981`)**<br>高对比度、磨砂玻璃、凌厉干练、专业仪表盘质感 |
| **伴侣默认身份** | **知心生活搭子（如：安比 Ambi 🐱）**<br>口吻松弛、体贴、会接梗、关注你的情绪与身体状态 | **首席商务幕僚（如：Looma Pro 💼）**<br>口吻精准、干练、结果导向、主动提示风险与死线 |
| **顶部防窥护盾** | 显示 `[🌱 私人生活空间 · 本地加密]` | 显眼展示 **`[🛡️ 投屏防窥已开启 · 私人记忆已物理隐藏]`** |
| **挂载记忆库** | 仅读取与写入 `life_vault`（饮食、喜好、亲友、私房钱） | 仅读取与写入 `work_vault`（客户、合同、报价、项目排期） |
| **跨态单向感知** | 可感知今天在【搞钱态】下的高强度工作并给予温柔慰问 | **绝对禁止**读取任何【生活态】的隐私数据 |

## 二、 核心交互闭环：「无感意图嗅探」与「双向活体绑定」

### 2.1 嘴动卡变（Talk-to-Live-State）四步零摩擦闭环
1. **随口输入**：用户在底部输入框打字、点选预设气泡、或拖入一张图片（如：*“今天打车花了 32，午饭吃了 45；另外刚跟张总确认，下周三签合同，金额 15 万”*）。
2. **毫秒级意图嗅探（Intent Sniffing）**：
   * 引擎自动识别出这句话包含 **2 条生活花销变动** + **1 条商务跟进状态更新**。
3. **卡片原地生长/数值跳动 + 胶囊提示（Toast Mutation Badge）**：
   * 聊天框内伴侣用自然语言回复的同时，消息气泡下方自动附带一枚可点击的 **【⚡ 状态已自动更新】动态徽章**：
     * `💰 随口记账：+2 笔支出（¥77.00），本月预算剩余 82%`
     * `🤝 客户跟进 [张总]：阶段跃升至「待签合同」，金额锁定 ¥150,000`
4. **一键跳转检验**：点击该徽章，主视图平滑切换至对应的**活体状态卡（Living Card）**，修改过的字段高亮闪烁 1.5 秒。

### 2.2 手动嘴知（Click-to-Acknowledge）反向联动
* 用户在查看任意活体状态卡时，无需打字，直接点击卡片上的交互控件（例如：点击饮水卡的 `[+1 杯水]`、勾选项目卡的 `[✓ 初稿已交付]`、或点击客户卡的 `[🔥 推进阶段]`）。
* 状态更新的同时，底部伴侣状态栏立刻弹出一条**实时微反馈语音/文字泡泡**（如：*“叮！今天第 5 杯水达成，离满血状态只差 3 杯啦～”* 或 *“漂亮！初稿交付完毕，我已经帮你在日志里记下这个里程碑了。”*）。

## 三、 ToC【🌙 生活态】三大王牌活体卡规格

### 3.1 王牌卡 C1：💰《随口记账与心愿小金库》
* **解决痛点**：传统记账软件要选分类、填金额、写备注，90% 的人坚持不过 3 天。
* **自然语言触发示例**：
  * *“早饭包子8块，刚刚没忍住买了件299的外套”*
  * *“今天发工资啦，存入小金库 3000 块！”*
* **卡片可视化结构**：
  * **顶部：月度预算血条（HP Bar）**：动态进度条展示本月剩余可用额度，低于 20% 时变为琥珀预警色。
  * **中部：心愿攒钱罐（Wish Jar）**：如“日本旅行基金 / 新显卡基金”，展示当前达成百分比与一键 `[+ 存入一笔]` 按钮。
  * **底部：今日流水微账单**：自动按“餐饮☕ / 购物🛍️ / 出行🚕 / 娱乐🎮”归类并支持一键删除误记项。

### 3.2 王牌卡 C2：⚡《三维人生状态栏（RPG 个人面板）》
* **解决痛点**：把枯燥的健康管理、习惯打卡变成像游戏一样直观上瘾的“个人属性面板”。
* **自然语言触发示例**：
  * *“昨晚熬夜到两点，今天头昏脑胀的”*（自动扣减精力值，状态变更为 `😴 睡眠不足`）
  * *“今天晨跑了 5 公里，最新体重 63.8kg！”*（体能经验值 +20，更新体重曲线）
* **卡片可视化结构**：
  * **三大核心属性条**：`🔋 今日精力值 (0-100%)`、`💧 今日饮水格 (8格点亮)`、`⚖️ 当前体重/目标差值`。
  * **快捷微操作按钮**：`[💧 喝一杯水]`、`[🏃 运动打卡]`、`[🛌 满血休息]`（点击即触发伴侣夸夸反馈）。
  * **当前 Buff 标签**：如 `🔥 连续专注`、`☕ 咖啡因加持`、`🌙 急需补觉`。

### 3.3 王牌卡 C3：❤️《人间关系与重要人脉档案簿》
* **解决痛点**：记不住朋友/伴侣/长辈的生日、忌口、衣服尺码、送礼历史，临到关键时刻抓瞎。
* **自然语言触发示例**：
  * *“记一下，老陈不能吃香菜和海鲜，他女儿今年9月刚上大学。”*
  * *“妈妈下个月15号生日，她最近好像腰不太舒服。”*
* **卡片可视化结构**：
  * **人物星标卡片流**：每个人物一张精致档案卡，展示 `[关系标签]`、`[⚠️ 忌口与雷区]`、`[🎁 喜好与心愿]`、`[📅 重要纪念日倒计时]`。

## 四、 ToB【💼 搞钱态】三大王牌活体卡规格

### 4.1 王牌卡 B1：🤝《零填表·客户商机跟进卡（轻量活体 CRM）》
* **解决痛点**：销售、咨询顾问、工作室主理人痛恨填繁琐的 CRM 表单，但又怕忘掉高价值客户的跟进节点与底牌。
* **自然语言触发示例**：
  * *“刚见完星辰科技的李总，他们想做企业培训，预算在 18 万左右，痛点是新员工留存率低，下周四前我要发一份定制方案过去。”*
  * *“李总今天微信回我了，预算批到了 20 万，进入商务谈判阶段！”*
* **卡片可视化结构**：
  * **商机漏斗看板**：客户名 + 预计金额（`¥200,000`）+ 阶段进度条（`初步接触 → 需求确认 → 方案报价 → 商务谈判 → 赢单成交`）。
  * **核心情报摘要**：自动提炼的 `[🎯 客户核心痛点]`、`[💰 预算与底线]`、`[⏰ 下一步行动与死线]`。
  * **快捷推进操作**：点击阶段按钮可直接跃迁状态；点击 `[📤 生成客户对齐单]` 直接联动 B3 卡片。

### 4.2 王牌卡 B2：🎯《碎碎念·项目死线推进看板》
* **解决痛点**：微信群里老板和同事发了一堆语音和散乱要求，整理成待办事项极其费神。
* **自然语言触发示例**：
  * *“把这周要交的三件事记一下：周三前完成主视觉设计，周五前把接口联调完，周日准备发布会彩排。”*
* **卡片可视化结构**：
  * **里程碑进度环**：总体完成度百分比（如 `66%`）。
  * **可交互任务清单**：带优先级标签（`🔴 紧急` / `🟡 正常`）与截止日期的勾选列表，勾选 `[✓]` 时伴侣实时播报战果并计算剩余工作负荷。

### 4.3 王牌卡 B3：📤《一键外发·高颜值客户交付对齐单》
* **解决痛点**：跟客户或合作方聊完后，谁能最快发出一份清晰、专业、排版精美的《沟通确认回执单》，谁就能瞬间建立极高的专业信任感（同时实现产品的病毒裂变）。
* **核心功能**：
  * 可从任意《客户跟进卡》或《项目看板》一键提取公开字段（**自动过滤内部底价、私人吐槽等敏感信息**）；
  * 渲染为一张**黑金/极简白商务质感的高清确认函卡片**（含：项目名称、已达成共识项、我方下一步交付物与时间点、客户待确认事项）；
  * 支持 **一键导出高清 PNG 长图**（直接发微信群），底部附带优雅微签名：`由 Looma 灵犀工作台自动生成`。

## 五、 杀手级扩展：「一句话自定义新活体卡」与双手帐

1. **一句话造卡（One-Sentence Custom Card）**：
   * 除了内置的 6 大王牌卡，用户只需点击 `[+ 一句话造新卡]` 并输入任意需求（例如：*“帮我建一张《备考雅思倒计时与错题本》卡”* 或 *“帮我建一张《咖啡店每日原料库存预警》卡”*），系统立即生成包含状态指标、进度条与检查项的专属活体卡！
2. **双态总结产物（今日生活手帐 vs 今日商务战报）**：
   * 在【🌙 生活态】下，可一键生成温润治愈的 **《今日双人生活手帐》**；
   * 在【💼 搞钱态】下，可一键生成干练清晰的 **《今日商务推进日报 / 周报卡片》**（再也不用痛苦憋周报，一键复制文本或导出图片交差）。

## 六、 让普通用户给出“五星封神评价”的 8 个魔鬼细节

1. **零 API Key 也能爽玩全部核心功能**：内置强大的本地语义嗅探与算式引擎，哪怕用户一分钱不充、一个 Key 不填，说“午饭花了35”、“新增客户张总预算10万”，卡片照样毫秒级自动创建并精准计算！
2. **一秒体验魔法的「新手演练胶囊」**：底部常驻 3 个一键体验按钮（如 `[✨ 试一试：随口记笔账]`、`[💼 试一试：一句话建客户档]`），新用户点一下就能亲眼看到“说话即建表改数”的全过程。
3. **每一次状态变更都有“多巴胺微反馈”**：数值跳动时的微光动画 + 伴侣恰到好处的一句情绪价值回应。
4. **防社死红线提示**：切入【💼 搞钱态】时，顶部亮起醒目的翡翠绿防窥盾牌，给职场人 100% 的安全感。
5. **随时可反悔的记忆与状态**：所有自动提取的记忆和账单/商机，鼠标悬停即可一键划掉或修改，绝不绑架用户。
6. **高颜值可晒图（Social Currency）**：导出的手帐卡和商务回执单均采用杂志级排版（2倍超清渲染），发到朋友圈或客户群极具面子。
7. **极低资源占用与丝滑折叠**：一键收起为屏幕边缘仅占 200×50 像素的精致灵动胶囊，呼之即来，挥之即去。
8. **100% 本地主权与一键迁移**：支持将双保险箱数据完整导出为 JSON 资产包，彻底消除“平台跑路数据丢失”的恐惧。
