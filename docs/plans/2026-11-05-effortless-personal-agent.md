# 随心记下实施计划

依据：已确认的 docs/specs/2026-11-05-effortless-personal-agent.md。保留当前分支及所有既有清理、归档、接续、后台提醒改动，不提交、不推送。

1. 原生模型传输：复用用户已配置连接，新增有界captureAgentModel请求；只发送当前空间、限定待办与相关会话，不带凭据进renderer或备份。Electron与Android同契约，旧propose/recall兼容。
2. Personal Agent服务：严格模型JSON校验、来源引用、当前实体/revision检查、幂等创建、多事项、纠正及保守状态修改；无模型时回退本地并保留原文。简单本地指令低延迟；复杂输入不得被旧单事项规则吞掉。
3. 工作态快速入口：首页即可随口记，客户/项目和高级核对按需展开，不修改重要事实核对语义；生活/工作共享理解服务，原文保存成功后即承认已记录。
4. 集成与失败恢复：模型超时、跨空间切换、备份恢复丢弃旧结果；补充时间、改口、歧义不误操作。模型失败不得让用户重说；提供非阻塞重试整理入口。
5. TDD与口语语料：200条单句、40条多轮，人工预期状态；本地和模型成对对比，记录错误而非自评成功。
6. 独立审查、全量测试、真实浏览器、SQLite与Android编译；最终构建、签名并测试打包EXE。模型测试用gpt-6.1-sol，凭据仅进程注入；不可用时准确报告未测。

执行裁定：语音转写不在本轮另接付费服务/依赖；沿用系统输入法语音输入。不要为“伙伴”添加无关聊天、人设、积分或强制日历规划。
执行裁定：不因“随心记下”擅自确认预算或客户承诺；非阻塞收下原文与正式商业确认是两件事。
