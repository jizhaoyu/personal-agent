# Looma（灵犀胶囊）软件操作与使用说明书

版本：v5.1 · 编制日期 2026-11-02。适用平台：Windows 10/11 (x64) 桌面客户端、Web 预览端及 Android 移动适配端。

---

## 第一章 系统概述与产品定位

### 1.1 软件简介
Looma（灵犀胶囊）是一款面向独立接单者、咨询顾问、自由职业者与小工作室主理人的本地优先（Local-First）客户跟进与生活伴侣软件。系统旨在解决自由职业者在频繁沟通中“记不清、被打断接不上、隔天遗漏、错误难改”的痛点，帮助用户在刚结束沟通时快速完成清楚收尾，并在下次回归时提供准确可靠的接续起点。

### 1.2 核心价值与设计哲学
- **本地优先，绝对可控**：核心业务数据落盘于本地 SQLite 数据库或浏览器 IndexedDB，不强制依赖任何云端中心服务器，杜绝客户商业隐私外泄。
- **双态逻辑隔离**：严格划分“工作态”与“生活态”，两套空间的数据、记忆、统计与交互互不混淆，防止工作压力侵蚀生活状态。
- **核对先于落盘**：推断实体与变更必须经过“四类核对”（核对内容、我方下一步、等待客户、仍待确认）并由用户主动确认，系统绝不臆测事实。
- **原子事务收尾**：确认收尾将业务变更、事件记录、持久回执与草稿归档封装于同一本地事务，生成带有防重试机制的唯一回执单。
- **原创伴侣小精灵**：暖白浅绿原创小精灵伴侣，真实跟随工作状态与情绪反馈，支持 220×96 极简桌面悬浮胶囊模式。

## 第二章 运行环境与安装启动

### 2.1 系统与硬件要求
- **操作系统**：Windows 10 / Windows 11 64位操作系统（macOS / Linux 可通过源码编译运行）。
- **运行环境**：Node.js 20.x 或 24.x（仅源码运行需要；独立便携版无需安装 Node 环境）。
- **硬件配置**：最低 2 核 CPU、4GB 内存、500MB 可用磁盘空间；推荐 8GB 内存以获得最佳渲染与检索体验。

### 2.2 启动与部署方式

#### 方式一：独立便携版（推荐终端用户）
1. 解压便携包至本地独立非系统盘目录（例如 `D:\Tools\Looma-win32-x64\`）。
2. 双击运行目录下的 `Looma.exe` 即可启动应用。
3. 数据文件自动保存在系统安全用户目录，无需配置环境变量。

#### 方式二：快捷批处理启动（开发与日常维护）
项目根目录提供 `启动伴侣.bat`，双击运行将自动执行环境检查：
1. 检测依赖完整性，若缺少依赖自动执行 `npm ci`。
2. 触发增量构建 `npm run build`，确保加载最新编译资源。
3. 安全启动 Electron 桌面应用窗口。

#### 方式三：开发者命令行启动
打开 PowerShell 或终端，进入项目根目录：
- 安装依赖：`npm ci`
- 桌面热重载启动：`npm run dev`
- 仅浏览器 Web 预览：`npm run dev:vite`（默认监听 `http://localhost:5173`）
- 生产构建与启动：`npm run build` 紧接 `npm start`
- 打包便携验证包：`npm run package:trial`

## 第三章 工作台核心功能操作指南

### 3.1 沟通记录整理与草稿自存
1. **进入工作台**：启动应用后默认进入工作空间主看板。
2. **输入沟通信息**：在顶部或快捷输入框中粘贴微信、飞书、电话会议后的原始沟通文本。
3. **500毫秒防丢机制**：当停止键入 500 毫秒后，系统自动在本地持久化当前草稿，状态栏即时显示“草稿已保存”。切换到记忆中心、生活态或重启程序后均可无缝接续。
4. **触发提取**：点击“智能核对”按钮，系统依据本地规则引擎（或可选配置的模型）提取候选实体。

### 3.2 四类核对与语义辨析
在提交收尾前，系统弹出“提议核对”弹窗，将提取信息清晰拆分为四类卡片：
- **核对内容**：识别出的客户名称、合作项目、阶段变更及预算变更。
- **我方下一步**：明确需要我方执行的待办事项与截止日期。
- **等待客户**：明确需要客户提供素材、反馈或确认的事项，独立计时。
- **仍待确认**：尚未敲定金额、需求存在歧义的问题项，绝不伪造确定结论。

用户可直接在核对卡片中进行微调、字段剔除或修改归属。

### 3.3 原子收尾确认与持久回执
1. 核对无误后点击“确认收尾”。
2. 系统在单一事务内完成：写入最新业务字段、追加变更历史事件、生成持久收尾记录、结束并归档草稿。
3. 界面展示收尾回执单（Closure Receipt），包含保存清单与后续快捷操作入口。若存在未定问题或等待事项，回执明确标注“部分事项待推进”，绝不虚报“全部完结”。

### 3.4 Bento 三列敏捷看板
工作台采用现代 Bento 格局，分为三列直观呈现：
- **第一列（未完草稿与跟进）**：显示最近保存的沟通草稿、待录入提醒及当前正在进行的会话。
- **第二列（今日与逾期行动）**：高亮展示今日截止事项与历史逾期待办，提供一键完成与快速延期操作。
- **第三列（等待客户与未定事项）**：罗列等待客户答复的事项与遗留未定问题，防止因责任错配而耽误交付进度。

### 3.5 沟通纪要草稿生成与外发
1. 在项目或收尾回执点击“准备纪要”，打开独立纪要对齐窗口。
2. 勾选允许外发给客户的字段（系统默认排除内部预算、私密备注与未核准内容）。
3. 预览排版后，点击“复制文本”粘贴至即时通讯软件，或点击“导出 PNG”生成清晰的图片卡片发给客户核对确认。

## 第四章 生活态空间与伴侣小精灵

### 4.1 空间无缝切换与隔离保证
点击应用右上角或悬浮坞的“空间切换”按钮，即可在工作态与生活态之间一键切换。生活态涵盖个人状态、习惯记录与生活账单，完全与客户数据物理逻辑隔离。

### 4.2 原创伴侣小精灵互动
- **形象外观**：暖白浅绿、圆润豆形双叶冠造型，纯本地轻量 SVG 渲染。
- **情绪状态感知**：小精灵表情与动作跟随真实操作状态（空闲、处理中、成功保存、提醒、待核对、错误等），杜绝虚假打扰。
- **减少动态设置**：支持系统级减弱动态效果，兼顾专注与趣味。

### 4.3 桌面极简胶囊悬浮窗
1. 点击标题栏的“胶囊模式”图标，主窗口立即收起为 220×96 像素的迷你悬浮胶囊。
2. 胶囊停靠在桌面边缘，脱敏显示当前角色状态与待办数量，绝不暴露客户名称、项目金额或私密正文。
3. 单击胶囊即可瞬间恢复完整工作台，支持双向平滑切换。

### 4.4 生活记录与健康联动
- **饮水打卡与精力联动**：记录每日饮水次数与水量，自动计算并联动恢复精力值。
- **记账与金库沉淀**：清晰记录收支流水，收入类金额全额沉淀入个人金库，支出卡片实时展示近期小计。
- **心愿清单与便签**：分组管理愿望与购买计划，随手记录生活灵感。

## 第五章 长期记忆中心与大模型配置

### 5.1 本地长期记忆架构
- **分层记忆治理**：分为“近期会话层”、“已确认事实层”、“当前业务实体层”、“历史原始档案层”。
- **随口说与单字即时检索**：支持日常零碎信息输入，具备高灵敏单字全文模糊索引，毫秒级定位历史记录。
- **记忆事实更正与主动遗忘**：用户可对已提取的事实进行人工审阅、标记置顶、修正更正，或执行“主动遗忘”彻底清除关联推断与引用。

### 5.2 AI 大模型服务接入与安全规范
1. **支持协议**：支持符合 OpenAI 标准格式的云端模型（如 DeepSeek、通义千问等）及本地 Ollama 离线推理服务。
2. **Windows DPAPI 凭据安全存储**：API Key 等敏感连接信息由 Electron 主进程调用 Windows 操作系统底层安全加密（CryptProtectData）存储，不以明文保存在磁盘或配置文件中。
3. **独立回忆授权控制**：记忆模型增强（memoryModelEnabled）默认处于关闭状态。仅在用户主动发起回忆检索并明确勾选时，方将最小必要证据切片提交至模型，全库及未授权数据严禁出境。

## 第六章 演练模式与数据备份容灾

### 6.1 5.1“放心练习一次”演练沙箱
为了让新用户或团队成员无顾虑熟悉操作，系统提供独立演练沙箱：
1. 点击工作台“放心练习一次”入口。
2. 演练过程完全在当前窗口内存中运行，不触碰本地 SQLite 与 IndexedDB 数据库。
3. 关闭演练窗口后，全部模拟草稿、模拟客户与模拟待办立即销毁，真实业务零污染。

### 6.2 完整备份导出与流式还原
- **全量导出**：在设置面板中点击“导出完整备份”，桌面端输出标准化流式 JSONL 文件，Web 端导出 JSON 归档文件（包含双空间业务、草稿、跟进、收尾记录与事实层，自动剔除敏感 API Key）。
- **校验与原子替换**：导入外部备份时，系统首先对文件格式、版本兼容性与字段完整性执行严格静态校验，校验通过后在单一事务内原子替换底层数据，避免因中断导致数据损毁。
- **存储路径对照**：
  - Windows 桌面版 SQLite：`%APPDATA%\Looma\looma.sqlite`
  - 浏览器端存储：IndexedDB `looma-local-v4`

## 第七章 常见问题排查与维护手册

### 7.1 常见故障自查表

| 故障现象 | 可能原因 | 解决办法 |
| :--- | :--- | :--- |
| 启动时提示 better-sqlite3 模块缺失或 ABI 不匹配 | Node.js 与 Electron 原生 ABI 版本不一致 | 执行 `npm run prepare:sqlite` 重新编译原生绑定库 |
| 模型配置后提示连接超时或拒绝访问 | API 端点地址错误或本地 Ollama 未启动 | 检查端点 URL 格式，确保 Ollama 正在监听 11434 端口 |
| 快捷启动 bat 弹窗闪退 | 本地未安装 Node.js 或环境变量 PATH 丢失 | 安装 Node.js 20 LTS 并重启命令行终端 |
| 无法在桌面显示胶囊悬浮窗 | 窗口缩放或多显示器负坐标越界 | 在主窗口设置中点击“重置窗口位置”恢复居中默认坐标 |
| 备份文件导入提示“结构校验失败” | 备份文件被第三方编辑篡改或版本跨度过大 | 检查 JSON/JSONL 文件语法，恢复原始纯净导出文件 |

### 7.2 核心操作快捷键清单
- `Ctrl + Enter`：在输入框内快速触发智能提取与核对
- `Esc`：快速关闭当前弹出的核对窗、设置窗或纪要预览
- `Ctrl + Shift + S`：快速切换工作态与生活态空间
- `Ctrl + M`：快速收起或展开桌面极简悬浮胶囊
