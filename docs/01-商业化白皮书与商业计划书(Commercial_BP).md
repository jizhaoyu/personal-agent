# Looma（灵犀胶囊）商业化白皮书与商业计划书 (Commercial Whitepaper & BP)

> **产品代号**：Project Looma（灵犀胶囊）  
> **物种定义**：全球首款 **“零填表”活体状态伴生系统（Talk-to-Live-State Companion OS）**  
> **核心定位**：对内是普通人零门槛的“生活状态管家（ToC）”，切入工作即化身为职场人与小微团队消灭填表之苦的“首席商务幕僚（ToB）”。

---

## 一、 执行摘要：为什么世界上还没有这款产品？

当前全球 AI 市场陷入了一个巨大的**“体验与商业化撕裂带”**：

1. **左端：传统生产力工具与 SaaS（Notion、飞书多维表格、Salesforce、各类记账/CRM 软件）**
   * **致命痛点**：它们本质上都是**“披着现代外衣的数据库”**。要想获得井井有条的看板，用户必须先扮演“数据库管理员（DBA）”——建表、设字段、选下拉框、每天手动录入。
   * **真实数据**：个人记账与习惯打卡类 App 的 **30 天留存率不足 8%**；企业销售人员平均每天花费 **1.8 小时** 手动填写 CRM 跟进记录，73% 的销售视其为“最痛苦的行政负担”。
2. **右端：拟人陪伴与酒馆生态（Character.AI、星野、SillyTavern）**
   * **致命痛点**：拥有极高的日均时长与情感黏性，但**困在“纯文字气泡”与“虚构角色扮演”里**。聊了十万字，关掉窗口后现实生活与工作没有任何实质推进，不仅难以破圈到普通大众，更无法进入高客单价的 ToB 商业场景。
3. **Looma 的历史性缝合（全球首创物种）**：
   * 我们提取了 SillyTavern（酒馆）高阶生态中最具生命力的隐藏机制——**“动态状态栏（Status Bar）+ 自动世界书（Auto Lorebook）”**，以及 Rokku 的 **“日常上下文先于任务 + Artifacts（共同交互产物）”** 哲学，并将其彻底重构为面向真实世界的 **Talk-to-Live-State（对话即活体状态）引擎**。
   * **颠覆性体验**：**用户永远不需要建表、永远不需要填格子！** 只管像跟微信好友或贴身秘书说话一样，在桌面浮窗随口说一句话或甩一张截图，Looma 一边给予高情商回应，一边在后台**全自动嗅探意图、建档、改数值，并在侧边实时刷新可视化的“活体状态卡（Living Artifacts）”**。

## 二、 核心痛点与第一性原理推导

### 2.1 三大不可逆的痛点真相

| 痛点维度 | 普通用户 (ToC) 的真实崩溃瞬间 | 职场人/小微企业 (ToB) 的真实崩溃瞬间 | Looma 的一招破局 |
| :--- | :--- | :--- | :--- |
| **1. 录入摩擦 (Input Friction)** | “今天买了咖啡、交了水电费、称了体重，但我懒得打开三个 App 选分类填数字，算了不记了。” | “刚见完三个客户，脑子里全是预算、痛点和下次跟进时间，但回到工位面对密密麻麻的 CRM 表单，一个字都不想填。” | **随口说 = 自动填**：一句话同时包含花销、体重或客户预算，系统毫秒级拆解并更新到多张活体状态卡。 |
| **2. 黏性信息丢失 (Sticky Info Loss)** | “上次朋友说他海鲜过敏、丈母娘喜欢某牌子茶叶，临到送礼时翻遍微信聊天记录也找不到。” | “三个月前答应客户的特殊折扣条款和交付红线，换了个对接人或隔了几周就全忘了，导致客诉丢单。” | **免维护记忆时光轴**：聊天时自动捕捉人物忌口、合同红线与承诺，在卡片上高亮置顶，永不遗忘。 |
| **3. 交付与对齐成本 (Alignment Cost)** | “想和伴侣/室友对一下这个月的攒钱进度或旅行准备清单，发一堆文字对方根本不看。” | “和客户开完会，还要花半小时排版一份《会议确认函/报价回执单》发微信群请客户确认。” | **一键外发高颜值交付单**：内部活体卡一键脱敏，秒变极具设计感的《交互式确认回执海报》，发微信群一秒对齐。 |

## 三、 核心护城河：「日夜双生保险箱」与双向活体引擎

为什么市面上的个人助手进不了公司，而企业软件又没人愿意在下班后用？因为**“公私不分、容易社死”**。Looma 独创三大架构壁垒：

```
                 【Looma 日夜双生双态架构】
 ┌───────────────────────────┬───────────────────────────┐
 │      🌙 生活态 (ToC)       │      💼 搞钱态 (ToB)       │
 ├───────────────────────────┼───────────────────────────┤
 │ • 视觉：羊皮纸暖调 + 治愈风  │ • 视觉：深空黑金 + 极简商务风 │
 │ • 角色：温暖生活搭子         │ • 角色：干练首席商务幕僚      │
 │ • 存储：Life Vault 私人库  │ • 存储：Work Vault 业务库   │
 │ • 王牌卡：                 │ • 王牌卡：                 │
 │   1. 💰 随口记账与小金库     │   1. 🤝 客户商机跟进 CRM 卡  │
 │   2. ⚡ 人生状态 RPG 血条   │   2. 🎯 项目死线推进看板     │
 │   3. ❤️ 人脉与亲友档案簿    │   3. 📤 客户交付对齐回执单   │
 └─────────────┬─────────────┴─────────────┬─────────────┘
               └──────► 单向温情桥接 ◄──────┘
          (仅传递“今日工作繁忙度/精力消耗”，绝不泄露业务机密与私人隐私)
```

1. **物理级防社死隔离（Dual-Vault Isolation）**：
   * 顶部一键切换 **【🌙 生活态】** 与 **【💼 搞钱态】**。
   * 切入【💼 搞钱态】瞬间，界面蜕变为冷峻高级的黑金商务工作台，开启 `[🛡️ 投屏防窥已保护]` 模式，**100% 物理隐藏所有私人账单、体重、情感倾诉与私密记忆**。就算老板或客户站在身后看你投屏，只会惊叹于你极其专业的商机看板。
2. **双向活体绑定（Two-Way Live Binding）**：
   * **嘴动卡变（Talk-to-Mutate）**：用户在聊天框说*“王总把预算从 8 万加到 12 万了，另外今天早饭花了 15 块”*，引擎自动将 12 万写入 Work 库的《王总 CRM 卡》，将 15 元记入 Life 库的《今日荷包卡》。
   * **手动嘴知（Click-to-Acknowledge）**：用户直接在卡片上勾选 `[✓ 已发送合同]` 或点击 `[+1 杯水]`，伴侣立刻在对话框冒泡反馈（*“合同发出去啦！离这单落袋为安只差临门一脚～”*），让冰冷的软件拥有“活人陪伴感”。

## 四、 商业模式与 PLG 增长飞轮（ToC 养口碑，ToB 赚大钱）

Looma 抛弃了早期 AI 产品低毛利的“倒卖 API Token 差价”模式，采用经过 Slack、Notion、飞书验证的 **PLG（产品驱动增长）三级火箭商业模型**：

### 4.1 病毒式自然裂变引擎（Zero-CAC Acquisition）
* **外发卡片即广告（Artifact as a Business Card）**：
  * ToC 用户将生成的《月度生活手帐 / 攒钱达成卡》发到小红书或朋友圈；
  * ToB 销售/顾问/设计师将生成的《客户方案对齐回执单》发给甲方客户微信群；
  * 每一张导出的高清卡片底部均带有克制高级的微印章（`Generated by Looma · 零填表活体工作台`）。收到卡片的甲方或朋友会被这种“不用填表就能生成高级看板”的体验震撼，转化为新用户。

### 4.2 三级定价矩阵与毛利结构

| 商业层级 | 目标客群 | 价格策略 | 核心权益与价值主张 | 预估毛利率 |
| :--- | :--- | :--- | :--- | :--- |
| **Tier 1：社区引力版**<br>*(Free / BYOK)* | 学生、极客、尝鲜大众 | **¥0 永久免费** | • 本地离线意图嗅探引擎（零配置开箱即用）<br>• 支持自填 API Key（DeepSeek / 本地 Ollama）<br>• 内置 3C + 3B 六大王牌活体卡 + 每日手帐导出 | **100%**<br>*(纯本地运行，零服务器成本)* |
| **Tier 2：个人 Pro 版**<br>*(ToC & 独立职场人)* | 白领、自由职业者、重度个人用户 | **¥28 / 月**<br>*(或 ¥268 / 年)* | • 免配置官方高速多模态通道（支持截图/语音直出卡片）<br>• 无限量「一句话自定义新活体卡」生成<br>• 端到端加密云备份与跨设备漫游 | **75% ~ 82%** |
| **Tier 3：团队与工作室版**<br>*(ToB 高毛利引擎)* | 销售团队、咨询顾问、买手店、MCN、律所 | **¥128 / 席位 / 月**<br>*(或企业私有飞地定制)* | • **多人嘴替汇总大盘**：团队成员各自跟桌面伴侣语音汇报，自动汇总成主管的《全局商机与项目总盘》<br>• **去水印企业专属品牌回执单**（定制公司 Logo 与配色）<br>• 团队共享客户记忆库（员工离职带不走客户上下文） | **85% ~ 90%** |

## 五、 全球竞争格局降维对比

| 维度 | 传统 SaaS / 笔记<br>*(Notion / 飞书表格 / CRM)* | 传统 AI 伴侣 / 酒馆<br>*(星野 / C.AI / SillyTavern)* | 通用大模型客户端<br>*(ChatGPT / 豆包)* | **Looma（灵犀胶囊）**<br>*(本项目)* |
| :--- | :--- | :--- | :--- | :--- |
| **建表与维护成本** | ❌ 极高（需手动设计表头、逐格填写） | ❌ 极高（酒馆需手写世界书与正则） | ⚠️ 中（每次需写长 Prompt，无持久面板） | ✅ **零成本（随口说话自动建卡改数）** |
| **持续留存锚点** | 结构化数据（但过程极其枯燥） | 情绪价值（但无现实产出，易腻） | 临时问答（用完即走，无沉淀） | **情绪陪伴 + 实时活体状态资产（双锚点）** |
| **ToC / ToB 兼容性** | 偏 ToB，个人用太重太累 | 纯 ToC 亚文化，办公场合打开即社死 | 杂糅混乱，公私记忆串台 | **🌙生活态 / 💼搞钱态 双库物理隔离瞬切** |
