## 已实现

- 原创暖白浅绿SVG小精灵与六种真实状态；工作/生活同一角色，键盘操作、减少动态效果，同一原生窗口220×96胶囊和原边界恢复。胶囊不展示业务原文、金额或客户字段。
- Electron主进程SQLite与Web原生IndexedDB；共享记录/事务校验，显式空间、字段前值和版本检查、整批写入/撤销、批次内容指纹幂等、来源关系和可重建索引。原生依赖由postinstall按Electron版本准备。
- 启动每类最多50条，记忆页30条游标分页，客户/行动/历史可搜索与加载更多。到期筛选查询所有历史任务；生活账单明确为已加载小计。输入按相关名字/索引载入必要上下文，不每次读取全库。
- 事实明确确认、重复识别、同主题冲突核对、纠正保留旧版本、置顶、来源查看与遗忘；原文默认本地保留，不随超过200条消息/500次事件自动截断。
- 当前业务、事实、摘要与原文分层。只读回忆先定位当前实体，默认最多12项/约4800字符；本地摘要仅根据最近40项以内已确认变更重建，不自动成为事实。
- 回忆模型授权独立且默认关闭，先展示依据，再主动发送已展示的当前空间证据；主进程复核授权、字段和长度，最多20项/8000字符，无写工具。保留已有OpenAI兼容/Ollama受控模型提取，不扩大原授权。
- 遗忘停用默认回忆并清理关联摘要；选择删除原文时，同事务清理索引、事件原文副本和撤销中的原文，停用共享该来源的事实，避免原文被业务撤销复活。独立业务字段和外部备份保留，属于逻辑删除。
- v3首次校验/来源指纹迁移，旧非凭据快照保留回退。桌面完整JSONL流式备份、暂存库完整校验/校验和、原子恢复；恢复期间拒绝并发修改。坏DB也能先校验有效备份、保留不可读文件后恢复。Web完整JSON导入导出及v3 JSON恢复，无旧5MB硬限制。
- 生活卡片、手记和设置异步保存成功后才更新回执；异步响应按空间和序列归属，失败不假报成功。

## 审查修复

- 设置后端返回失败不得显示成功；bootstrap错误显式反馈。
- 不同空间分别控制刷新序列，旧响应不能回滚新设置或丢弃当前分区。
- IndexedDB批次签名改为SHA256，避免在幂等表额外保存明文命令副本；相同ID不同内容被拒绝。
- 事实/原文删除同步传播到摘要、索引和撤销；独立确认业务值不随资料清理误删。
- 自然语言整句AND导致当前值漏检，改为有限关键词候选合并、实体优先；以实际IndexedDB索引验证当前预算。
- 历史列表兼容v3 operations和v4 mutations；切换列表类型不把旧行当成新类型渲染，防止崩溃或误操作。
- 恢复后重新初始化模式和缓存；大项目纪要关联行动分页完整读取，不静默只导出前200项。

## 明确限制与发布门槛

- npm官方registry实际审计：2项HIGH，位于现有Electron/extract-zip依赖链；默认镜像audit接口404，不能当作无漏洞。没有执行破坏性`audit fix --force`或未经批准跨大版本升级。公开分发前须完成Electron升级、对应原生ABI重建和桌面安全回归；本轮不声明可安全公开发布。
- 未用真实云模型凭据请求真实供应商；本机受控模型仅证明管线和失败边界，不能证明理解准确率。通知API返回shown:true，不证明系统横幅已被用户实际看到。
- 原始历史和磁盘占用会增长；有界工作集不是无限容量。浏览器全备份仍需足够内存/配额；SQLite业务文件未加密，逻辑删除不是取证级擦除。
- 旧v3截断过的数据不可恢复；回退快照和已导出备份是独立副本，当前删除不自动擦除它们。当前数据迁移机制已用合成资料验证，未替用户真实库执行验收。
- 本轮未创建签名安装包、推送Git、发布站点、发送客户材料或联系试用者。改动保留在本地feat/looma-trusted-mvp分支，未创建提交。
