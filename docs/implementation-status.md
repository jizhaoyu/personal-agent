# Looma 首轮优化实施记录

本文保留v3阶段的历史验收。2026-10-27后续SQLite、长期记忆与原创伴侣的当前实现及验证见implementation-v4-status.md；本文中的快照存储和依赖边界不代表v4当前状态。

设计与范围：用户已于 2026-10-26 批准真实案例试用版计划。

## 工作范围与行为锁定

- 工作态：解析无副作用，预览确认后原子提交，支持更正与倒序撤销。
- 保留生活态，禁止跨空间自动写入；备份无凭据，失败不覆盖。
- Windows 主进程连接模型；Web 仅本地流程；不推送、不发布、不发送客户材料。
- 复用现有依赖，以 Node 内置测试、构建、浏览器与 Electron 运行检查锁定行为。

## 分工与步骤

1. 核心：类型、v3 快照、迁移、候选解析、提交、撤销及回归测试。
2. 桌面：安全凭据、请求/取消/超时、通知、生产启动及测试。
3. 主界面：候选核对、工作台、纪要预览导出、设置与生活兼容。
4. 文档：Spec、实施清单、商业材料、Word 同步与渲染。
5. 集成：类型检查、全套测试、实际浏览器/Electron、最终独立审查。

## 实施决策

- 使用现有 checkout 的独立本地功能分支，无需另建工作树；初始工作区干净。
- 工作合作项目与旧 CRM 并存兼容接口；旧数据迁移时不推断客户关联或客户共识。
- 所有模型/外发内容都是用户可审阅草稿；不会把模型建议解释为事实。

## 验证记录

- `npm ci` 已安装锁定依赖，未新增应用或测试框架依赖。
- 第一轮完整构建通过后，Node 测试从45项扩展到53项；随后独立审查新增精确回归，预算/日期、模型语义、凭据迁移与生活原子性修复仍在收尾。最终结果以下方最终验收为准。
- 实际浏览器已验证：预览前业务为空、300元不放大、编辑350元后确认、刷新恢复、预算默认不外发、内部备注不入PNG、关联项目/行动同批撤销；长文本PNG已下载并目视复核。
- 实际浏览器已验证390px无横向溢出、双态隔离、坏备份不替换、有效备份恢复、损坏快照错误页恢复、迟到模型结果不覆盖确认/忽略/编辑/切换操作。
- 真实 Electron 已使用独立临时profile加载 `file:` 构建，真实Windows安全存储保存合成测试Key并重启恢复；主进程经loopback受控模型返回候选，确认前不写业务库，确认后保存；业务快照不含测试Key；原生通知API受理。该结果不代表真实云模型准确率或系统通知横幅必然可见。
- Word已从更新后的三份文档生成，使用WPS导出10页PDF并渲染逐页复核；兼容细节更新后将再次生成与复核。

## 审查后的实施决策

- 旧凭据安全迁移与旧明文清理解耦，已有连接时加密归档旧Key，不覆盖当前连接；清理失败支持重试。代价是增加一个仅主进程可读的加密迁移归档，用户清除模型配置时一并删除。
- 生活业务聚合成原子批次；输入原文与助手回复独立持久化。业务保存成功但回复保存失败时明确提示查看卡片、不要重复发送，避免误导重试。
- 浏览器与Electron集成脚本使用外部现成Playwright运行时和独立测试资料，不将Playwright加入应用依赖。
- 商业5用户7天试用未执行，不联系任何外部人员，也不生成虚构试用数据。
