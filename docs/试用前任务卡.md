# Looma 试用前 15 分钟任务卡

用途：正式七天试用前，由负责人安排 1—2 位没有参与开发的人做少指导观察。本卡不是已完成的访谈或试用结果，不自动联系任何人。

只使用演练环境或负责人准备的独立合成资料。先确认当前处于演练，不向真实工作区填入示例客户；不使用客户原文、联系方式、内部备注或真实凭据。不配置模型，先体验相同的本地基础流程。

## 给参与者的任务

1. 从“放心练习一次”中已填入的合成沟通开始，先读一遍原文。
2. 整理并核对，把示例预算改成 3500 元。分清自己的行动、等待客户的内容和仍未谈定的事项，再确认演练。
3. 查看演练项目，说出自己下一步做什么、正在等什么，再返回回执撤销这次演练。关闭并重开演练，确认它从初始示例开始；演练关闭即丢弃，不用于检验草稿重开恢复。
4. 中断恢复只在负责人单独准备的合成测试工作区观察：写一段合成记录，查看记忆或切换空间后回来继续，并尝试完成一项行动和撤销。不要使用日常客户工作区；没有准备独立测试工作区时，本项记录“未观察”，不强行执行。
5. 指出如果明天回来，你会从哪里找下一步。当天观察只记录“预计怎样找”；真正跨日找回需另一天观察，不能预填成功。

负责人开始前只解释这是试用和允许随时停止。让参与者自己尝试；若必须指导，记录指导发生在哪一步，不把有指导完成记为独立完成。15 分钟是安排时长，不是产品效率成绩。

## 负责人观察记录

| 项目 | 实际观察（尚未执行时留空） |
| --- | --- |
| 匿名编号、日期、构建编号、平台 | |
| 首次在哪里犹豫或停住 | |
| 哪个词或按钮没有理解 | |
| 核对与修正用了哪些步骤 | |
| 我方、客户、未定是否能分清 | |
| 中断后是否找回、是否受指导 | |
| 明天找回的预期路径／实际跨日结果 | |
| 最需要改的一处及其影响 | |

结束后询问：“现在你能说清楚，自己接下来要做什么、正在等客户什么吗？”允许回答没有帮助或不适用，原样记录脱敏意见。

遇到问题时打开应用的“版本与问题记录”，填写预期、实际和是否可重复，核对完整预览后再由参与者决定是否复制或下载分享。默认不收集数据库、客户原文、Key、接口地址或系统路径。详细七天记录继续使用同目录的《试用验证记录模板》。
