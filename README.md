## ✨ 为什么做 Looma (灵犀胶囊)？

市面上现有的 AI 产品与效率工具存在三大顽疾：
1. **传统表单软件（Notion / 记账 App / CRM 系统）反人性**：买杯咖啡要打开 App 点选 5 次分类，拜访完客户要在 CRM 填 15 个字段，90% 的普通人坚持不过 3 天。
2. **传统聊天伴侣（SillyTavern / 豆包 / ChatGPT）“聊完即焚”**：聊了上千句，关键账单、客户底牌、项目死线全部淹没在冗长的历史记录里，无法沉淀为结构化看板。
3. **重度 Agent 框架（OpenClaw / AutoGPT）门槛极高**：动辄配置 Docker、Python、API Key，且黑盒后台改文件容易误删数据。

**Looma (灵犀胶囊)** 独创 **“Talk-to-Live-State（对话即状态）”** 范式：
- **零填表自动显影**：你只管像跟老朋友聊天一样随口说一句“午饭花了35块”、“王总对海鲜过敏，预算50万”，底层毫秒级意图嗅探引擎自动更新右侧的**活体数据卡片**，并在聊天气泡下挂载 `⚡ 状态已自动更新` 微型回执胶囊。
- **ToC + ToB 双生隔离架构（Dual-Vault Architecture）**：底部一键切换 `🌙 生活态` 与 `💼 搞钱态`。生活态采用温暖焦糖羊皮纸画风，搞钱态切换为深邃黑金/冷灰极客商务风；两套记忆库物理隔离，仅通过“压力感知桥”单向传递关怀信号。
- **高颜值社交/商务卡片一键直出**：
  - **ToC 生活态**：一键导出拍立得质感 **《今日心情手账 PNG》**（发小红书/朋友圈）。
  - **ToB 搞钱态**：一键导出麦肯锡级排版 **《客户跟进备忘录 / 会议对齐单 PNG》**（直接发企业微信/飞书群，自带 `Generated by Looma` 品牌水印，驱动 B2C2B 病毒裂变）。

## 🚀 快速启动指南

### 1. 环境准备
确保已安装 [Node.js](https://nodejs.org/) (推荐 v18 / v20 / v24+)。

```bash
# 安装依赖
npm install
```

### 2. 启动 Web 预览模式（浏览器直接体验）
```bash
npm run dev
```
打开浏览器访问 `http://localhost:5173` 即可体验完整功能（内置零配置双态智能伴侣引擎，无需填写 API Key 即可开箱体验所有零填表活体卡片能力）。

### 3. 启动 Windows 桌面悬浮伴侣窗口（Electron 模式）
```bash
npm run electron:dev
```
将在桌面右下角启动无边框、毛玻璃质感的常驻伴侣胶囊窗口。

### 4. 生产环境打包验证
```bash
npm run build
```

## 🛠️ 技术栈
- **桌面容器**：Electron 34 (无边框透明悬浮窗 + 置顶常驻)
- **前端框架**：React 19 + TypeScript 5.7 + Vite 6
- **视觉体系**：Tailwind CSS + Lucide Icons (`🌙 生活态` 温暖羊皮纸主题 / `💼 搞钱态` 深邃黑金商务主题)
- **状态与卡片导出**：Tier-0 本地毫秒级正则意图解析器 + `html-to-image` 高清 2x 卡片渲染引擎 + OpenAI/DeepSeek 兼容接口
